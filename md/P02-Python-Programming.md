# المرحلة الثانية [P02]: لغة بايثون (Python Programming)

أنا مهندس برمجيات أهدف إلى بناء فهم هندسي متين يساعدني على تحليل المشكلات، وفهم سلوك الأنظمة، واتخاذ قرارات تقنية مبررة، وتطوير برمجيات موثوقة قابلة للاختبار والصيانة والتوسع. أفضّل استخدام **Python** و**PostgreSQL**، وأعتمد **FastAPI** في المسار التطبيقي لتطوير الخدمات الخلفية؛ لذلك تربط هذه الخطة بين الأسس النظرية والتطبيق العملي باستخدام هذه التقنيات.

**هدف المرحلة:** كتابة برامج بايثون منظمة، قابلة للاختبار، واضحة المسؤوليات، مع فهم طريقة عمل اللغة لا حفظ صياغتها.

## 1. أساسيات اللغة (Language Fundamentals)

- المتغيرات، أنواع البيانات، العمليات - Variables, Data Types, Operators
- القيم المنطقية، الشروط - Booleans, Conditionals
- الحلقات - Loops
- الدوال، المعاملات، القيم المرجعة، النطاق - Functions, Parameters, Return Values, Scope
- القوائم، الصفوف، المجموعات، القواميس - Lists, Tuples, Sets, Dictionaries
- التعامل مع النصوص - String Processing
- التعبيرات النمطية - Regular Expressions
- معالجة الاستثناءات - Exception Handling
- التعامل مع الملفات - File Handling
- الوحدات، الحزم، الاستيراد - Modules, Packages, Imports
- التوثيق النصي - Docstrings

## 2. أدوات العمل اليومي (Daily Tooling)

*تبدأ مع أول مشروع، وتستمر في كل المراحل.*

- الطرفية: التنقل، الملفات، الأنابيب، متغيرات البيئة - Terminal: Navigation, Files, Pipes, Environment Variables
- جيت: المستودعات، الالتزامات، الفروع، الدمج - Git: Repositories, Commits, Branches, Merge
- تعارضات الدمج، طلبات الدمج - Merge Conflicts, Pull Requests
- استراتيجية الفروع، الإصدارات الدلالية - Branching Strategies, Semantic Versioning
- البيئات الافتراضية - Virtual Environments
- إدارة الحزم، التبعيات، ملفات القفل - Package Management, Dependencies, Lock Files
- ملف إعدادات المشروع - Project Configuration File
- تنسيق الكود، فحص الجودة - Formatting, Linting
- المنقح، تتبع المكدس - Debugger, Stack Traces
- قراءة التوثيق الرسمي - Reading Official Documentation

## 3. المكتبة القياسية (Standard Library)

- المسارات، نظام الملفات - Paths, File System
- صيغ البيانات: JSON، CSV، التسلسل - Data Formats: JSON, CSV, Serialization
- التاريخ، الوقت، المناطق الزمنية - Date, Time, Time Zones
- الأعداد العشرية الدقيقة، الكسور - Decimal, Fractions
- الحاويات الخاصة - Specialized Containers
- الأدوات التكرارية، الدوال العليا - Itertools, Functools
- التسجيل - Logging
- معاملات سطر الأوامر - Command-Line Arguments
- العشوائية، التجزئة - Random, Hashing

## 4. نموذج البيانات (Data Model)

- الهوية، القيمة، المساواة - Identity, Value, Equality
- القابلية للتغيير، عدم القابلية للتغيير - Mutability, Immutability
- المراجع، الأسماء، النسخ السطحي، العميق - References, Names, Shallow Copy, Deep Copy
- القيم الافتراضية للمعاملات، فخ القيمة القابلة للتغيير - Default Arguments, Mutable Default Trap
- بروتوكول التكرار - Iteration Protocol
- الطرق الخاصة - Special Methods
- الأعداد العشرية بعمق، أخطاء التقريب - Floating-Point in Depth, Rounding Errors (IEEE 754)
- النصوص بعمق: يونيكود، الترميز، النص مقابل البايتات - Text in Depth: Unicode, UTF-8, Text vs Bytes

## 5. البرمجة الكائنية (Object-Oriented Programming)

- الأصناف، الكائنات، الخصائص، الطرق - Classes, Objects, Attributes, Methods
- التغليف، التجريد - Encapsulation, Abstraction
- الوراثة، تعدد الأشكال، التركيب - Inheritance, Polymorphism, Composition
- الأصناف المجردة، البروتوكولات - Abstract Classes, Protocols
- الخصائص المحسوبة، طرق الأصناف، الطرق الساكنة - Properties, Class Methods, Static Methods
- أصناف البيانات - Data Classes
- التعداد - Enumerations

## 6. البرمجة الوظيفية، المولدات (Functional Programming, Generators)

- الدوال النقية، الآثار الجانبية، عدم تغيير البيانات - Pure Functions, Side Effects, Immutability
- الدوال العليا، الدوال المجهولة، الإغلاقات - Higher-Order Functions, Lambda, Closures
- المزخرفات - Decorators
- المكررات، المولدات - Iterators, Generators
- الاشتقاقات - Comprehensions
- مديرو السياق - Context Managers

## 7. أنظمة الأنواع (Type Systems)

- التلميحات النوعية، الأنواع المركبة، الاختيارية - Type Hints, Compound Types, Optional Types
- الأنواع العامة، الأنواع البروتوكولية - Generics, Protocol Types
- التحقق الساكن من الأنواع - Static Type Checking

## 8. الذاكرة، بيئة التنفيذ (Memory, Runtime)

- نموذج المراجع، العد المرجعي - Reference Model, Reference Counting
- جامع القمامة، الدورات المرجعية - Garbage Collection, Reference Cycles
- البايت كود، الآلة الافتراضية - Bytecode, Virtual Machine
- نظام الاستيراد، تحميل الوحدات - Import System, Module Loading
- قياس الذاكرة، الزمن - Memory, Time Profiling

*التزامن (الخيوط، العمليات، البرمجة غير المتزامنة) مالكه المرحلة السابعة.*

## 9. تنظيم المشاريع، الجودة (Project Structure, Quality)

- بنية المشروع، الحزم - Project Structure, Packages
- إدارة الإعدادات، متغيرات البيئة - Configuration, Environment Variables
- اختبارات الوحدات الأولية - Basic Unit Tests
- تسجيل الأخطاء، معالجتها - Error Logging, Handling
- المراجعة الذاتية للكود - Self Code Review

## التدريبات العملية (Practical Exercises)

1. حل 30 مسألة صغيرة (حلقات، قوائم، نصوص، قواميس) على منصة تمارين (القسم 1).
2. أداة سطر أوامر تعد تكرار الكلمات في ملف نصي، تقبل مسار الملف، خيارات الترتيب، الحد الأعلى للنتائج (الأقسام 1، 2، 3).
3. أنشئ مستودع جيت: 10 التزامات واضحة، فرع جانبي، تعارض دمج متعمد ثم حله (القسم 2).
4. اقرأ ملف CSV لمصروفات، جمّعها حسب الفئة، أنتج تقرير JSON؛ استخدم الأعداد الدقيقة بدل العشرية، اشرح السبب (القسمان 3، 4).
5. أثبت عمليًا: ناتج 0.1 + 0.2، فخ القيمة الافتراضية القابلة للتغيير، الفرق بين النسخ السطحي، العميق، الفرق بين المساواة، الهوية (القسم 4).
6. نمذج نظام محفظة مالية: حسابات، معاملات، قواعد تمنع الرصيد السالب؛ ابنه بالتركيب أولًا، ثم قارنه بحل بالوراثة (القسم 5).
7. اكتب مولدًا يقرأ ملفًا كبيرًا سطرًا سطرًا، مزخرفًا يقيس الزمن، مزخرفًا يعيد المحاولة، مدير سياق يحرر مواردًا (القسم 6).
8. أضف تلميحات نوعية لمشروعك، شغّل أداة التحقق حتى تمر دون أخطاء (القسم 7).
9. قارن استهلاك الذاكرة بين قائمة، مولد؛ أنشئ دورة مرجعية وراقب جامع القمامة؛ افحص البايت كود لدالة بسيطة (القسم 8).
10. أعد تنظيم التمرين 4 كحزمة: بيئة افتراضية، ملف إعدادات، اختبارات، README، تسجيل (القسم 9).

**المخرج:** مشروعان في مستودع جيت: أداة سطر أوامر، حزمة صغيرة موثقة باختبارات، مع README لكل منهما.

**معيار الانتقال:**

- تكتب برنامجًا من نحو 300 سطر مقسمًا إلى وحدات، دون تكرار الكود بالنسخ.
- تشرح الفرق بين التعيين، النسخ، تتبع التغيير في الكائنات القابلة للتغيير.
- تقرأ تتبع المكدس، تستخدم المنقح لإيجاد خطأ.
- تستخدم جيت يوميًا دون خوف من التعارضات.
