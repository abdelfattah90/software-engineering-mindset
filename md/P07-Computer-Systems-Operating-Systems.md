# المرحلة السابعة [P07]: الحاسوب، أنظمة التشغيل (Computer Systems, Operating Systems)

أنا مهندس برمجيات أهدف إلى بناء فهم هندسي متين يساعدني على تحليل المشكلات، وفهم سلوك الأنظمة، واتخاذ قرارات تقنية مبررة، وتطوير برمجيات موثوقة قابلة للاختبار والصيانة والتوسع. أفضّل استخدام **Python** و**PostgreSQL**، وأعتمد **FastAPI** في المسار التطبيقي لتطوير الخدمات الخلفية؛ لذلك تربط هذه الخطة بين الأسس النظرية والتطبيق العملي باستخدام هذه التقنيات.

**هدف المرحلة:** فهم كيف ينفذ الحاسوب البرنامج، يدير الذاكرة، الموارد، التزامن، تشخيص مشكلات الأداء.

## 1. عمارة الحاسوب (Computer Architecture)

- المعالج، السجلات، دورة تنفيذ التعليمات - CPU, Registers, Instruction Cycle
- الذاكرة المخبئية، محلية البيانات - Cache Hierarchy, Data Locality
- الذاكرة الرئيسية، التخزين - Main Memory, Storage
- *اختياري:* نظرة على لغة التجميع - Assembly Overview

## 2. الذاكرة (Memory)

- المكدس، الكومة - Stack, Heap
- حجز الذاكرة، تحريرها، عمر الكائنات - Allocation, Deallocation, Object Lifetime
- الذاكرة الافتراضية، تقسيمها إلى صفحات - Virtual Memory, Paging
- تسرب الذاكرة، ضغط الذاكرة - Memory Leaks, Memory Pressure

## 3. أنظمة التشغيل (Operating Systems)

- النواة، فضاء المستخدم، استدعاءات النظام - Kernel, User Space, System Calls
- العمليات، الخيوط - Processes, Threads
- الجدولة، تبديل السياق - Scheduling, Context Switching
- أنظمة الملفات، الصلاحيات - File Systems, Permissions
- الاتصال بين العمليات، الأنابيب، الإشارات - Inter-Process Communication, Pipes, Signals

## 4. لينكس عمليًا (Linux in Practice)

- هيكل الملفات، المستخدمون، الصلاحيات - Filesystem Layout, Users, Permissions
- العمليات، الخدمات، السجلات - Processes, Services (systemd), Logs
- مراقبة الموارد - Resource Monitoring (top, free, df, iostat)
- الأوامر النصية - Shell Scripting
- الاتصال البعيد، المفاتيح - Remote Access, SSH Keys
- متغيرات البيئة، الإعدادات - Environment Variables, Configuration

## 5. التزامن، التوازي (Concurrency, Parallelism)

- ظروف السباق، المناطق الحرجة - Race Conditions, Critical Sections
- الأقفال، الإشارات، المتغيرات الشرطية - Mutexes, Semaphores, Condition Variables
- حالات الجمود، التجويع - Deadlocks, Starvation
- العمليات الذرية، رؤية الذاكرة - Atomic Operations, Memory Visibility
- سلامة الخيوط، البيانات غير القابلة للتغيير - Thread Safety, Immutability
- أنماط شائعة: المنتج والمستهلك، مجمع الخيوط - Common Patterns: Producer-Consumer, Thread Pool

## 6. الإدخال، الإخراج، الأداء (I/O, Performance)

- العمليات الحاجبة، غير الحاجبة - Blocking, Non-Blocking I/O
- تعدد الإرسال - I/O Multiplexing (select, epoll)
- الإدخال، الإخراج غير المتزامن، حلقة الأحداث - Asynchronous I/O, Event Loop
- المخازن المؤقتة - Buffering
- عمليات المعالج مقابل عمليات الإدخال، الإخراج - CPU-Bound vs I/O-Bound Workloads
- تحليل الأداء، الاختناقات - Performance Profiling, Bottlenecks

## 7. التزامن في بايثون (Concurrency in Python)

- خيط التنفيذ العام - Global Interpreter Lock
- الخيوط، مجمع الخيوط - Threads, Thread Pools
- تعدد العمليات - Multiprocessing
- البرمجة غير المتزامنة، الإلغاء، معالجة الاستثناءات - Asynchronous Programming, Cancellation, Exception Handling
- اختيار نموذج التنفيذ - Choosing an Execution Model
- متابعة النسخ الحرة من القفل - Free-Threaded Builds (راجع التوثيق الرسمي للحالة الحالية)

## التدريبات العملية (Practical Exercises)

1. اطبع حجم الذاكرة لكائنات مختلفة، راقب ذاكرة عملية أثناء تشغيلها، فسّر الفرق بين المكدس، الكومة بمثال (القسمان 2، 3).
2. تمرين لينكس: أنشئ خدمة بسيطة تُدار بمدير الخدمات، اقرأ سجلها، غيّر صلاحيات ملفاتها، أنهِ عملية، راقب الموارد، اكتب سكربت نسخ احتياطي بسيطًا (القسمان 3، 4).
3. أنتج ظرف سباق: عداد مشترك بين عدة خيوط يعطي نتيجة خاطئة؛ أصلحه بقفل، ثم بحل بلا قفل باستخدام طابور (القسم 5).
4. أنتج جمودًا عمدًا بقفلين، ثم أصلحه بترتيب ثابت للأقفال (القسم 5).
5. قارن ثلاثة نماذج لتنزيل 100 صفحة: متسلسل، خيوط، برمجة غير متزامنة؛ ثم ثلاثة لعمل حسابي ثقيل: متسلسل، خيوط، عمليات؛ اجمع النتائج في جدول، فسّرها بخيط التنفيذ العام (القسمان 6، 7).
6. اكتب خادم مقابس يخدم عدة عملاء بنسختين: خيط لكل اتصال، برمجة غير متزامنة؛ اختبرهما بألف اتصال (القسمان 6، 7).
7. حلل برنامجًا بطيئًا بأداة تحليل الأداء، حدد الاختناق، حسّنه، قس الفرق قبل التعديل، بعده (القسم 6).

**المخرج:** تقرير قياسات لنماذج التنفيذ، سكربتات لينكس موثقة، خادمان بنموذجين مختلفين.

**معيار الانتقال:**

- تشرح لماذا لا تسرّع الخيوط عملًا حسابيًا في بايثون، متى تنفع.
- تختار بين الخيوط، العمليات، البرمجة غير المتزامنة لمسألة جديدة، تبرر الاختيار.
- تشخص ارتفاع المعالج، امتلاء الذاكرة، امتلاء القرص بأوامر لينكس.
- تعرف متى تحتاج قفلًا، متى تتجنبه.
