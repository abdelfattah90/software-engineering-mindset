# المرحلة الرابعة [P04]: هياكل البيانات (Data Structures)

أنا مهندس برمجيات أهدف إلى بناء فهم هندسي متين يساعدني على تحليل المشكلات، وفهم سلوك الأنظمة، واتخاذ قرارات تقنية مبررة، وتطوير برمجيات موثوقة قابلة للاختبار والصيانة والتوسع. أفضّل استخدام **Python** و**PostgreSQL**، وأعتمد **FastAPI** في المسار التطبيقي لتطوير الخدمات الخلفية؛ لذلك تربط هذه الخطة بين الأسس النظرية والتطبيق العملي باستخدام هذه التقنيات.

**هدف المرحلة:** فهم كيف تُخزَّن البيانات، كلفة كل عملية، متى يُختار كل هيكل.

## 1. أساسيات الاختيار (Selection Fundamentals)

- العمليات الأساسية، كلفتها - Core Operations, Costs
- المصفوفات، التخزين المتجاور، محلية البيانات - Arrays, Contiguous Storage, Data Locality
- المصفوفات الديناميكية، الكلفة المستهلكة - Dynamic Arrays, Amortized Cost
- الهياكل المترابطة، المؤشرات، المراجع - Linked Structures, Pointers, References

## 2. الهياكل الخطية (Linear Structures)

- القوائم المترابطة: الأحادية، الثنائية - Linked Lists: Singly, Doubly
- المكدسات - Stacks
- الطوابير، الطوابير مزدوجة النهاية - Queues, Deques
- المخازن الدائرية - Circular Buffers

## 3. جداول التجزئة، المجموعات، الخرائط (Hash Tables, Sets, Maps)

- دوال التجزئة - Hash Functions
- معالجة التصادم: السلسلة، العنونة المفتوحة - Collision Handling: Chaining, Open Addressing
- عامل التحميل، إعادة التجزئة - Load Factor, Rehashing
- المجموعات، الخرائط - Sets, Maps

## 4. الأشجار (Trees)

- الأشجار الثنائية، اجتيازها - Binary Trees, Traversals
- أشجار البحث الثنائية - Binary Search Trees
- الأشجار المتوازنة (المفهوم) - Balanced Trees (Concept)
- أشجار B، علاقتها بالفهارس - B-Trees, Link to Database Indexes
- الأكوام، الطوابير ذات الأولوية - Heaps, Priority Queues
- أشجار البادئات - Tries

## 5. الرسوم البيانية، المجموعات المنفصلة (Graph Representations, Disjoint Sets)

- قائمة الجوار، مصفوفة الجوار - Adjacency List, Adjacency Matrix
- الاختيار بحسب كثافة الرسم - Choosing by Graph Density
- المجموعات المنفصلة - Disjoint Sets (Union-Find)

## 6. الهياكل في بايثون (Structures in Python)

- التنفيذ الداخلي للقائمة، القاموس، المجموعة - Internals of list, dict, set
- المفاتيح القابلة للتجزئة، ترتيب القاموس - Hashable Keys, Dict Ordering
- الحاويات القياسية - Standard Containers (deque, heapq, bisect, collections)
- بناء هيكل جديد بصنف - Implementing a Structure as a Class

## 7. اختيار الهيكل (Choosing a Structure)

- معايير القرار: العمليات المتكررة، الحجم، الذاكرة، الترتيب - Decision Criteria: Frequent Operations, Size, Memory, Ordering
- المفاضلات، تبريرها - Trade-offs, Justification
- *اختياري:* قوائم التخطي، مرشح بلوم، الأشجار المتقدمة - Skip Lists, Bloom Filters, Advanced Trees

## التدريبات العملية (Practical Exercises)

1. نفذ من الصفر: مصفوفة ديناميكية، قائمة مترابطة، مكدس، طابور، جدول تجزئة مع إعادة التجزئة، شجرة بحث ثنائية، كومة صغرى؛ اختبر كل هيكل (الأقسام 1 إلى 4).
2. قارن عمليًا: البحث في قائمة مقابل مجموعة بمليون عنصر، الإدراج في أول قائمة مقابل الطابور مزدوج النهاية (القسمان 1، 6).
3. ابنِ مخزن الأقل استخدامًا حديثًا (LRU Cache) بجدول تجزئة مع قائمة مترابطة ثنائية، ووثق تعقيد كل عملية (القسمان 2، 3).
4. تحقق من توازن أقواس تعبير بمكدس، ثم قيّم تعبيرًا رياضيًا بالصيغة اللاحقة (القسم 2).
5. أنشئ إكمالًا تلقائيًا لقاموس كلمات بشجرة بادئات (القسم 4).
6. مثّل شبكة (مدن، تبعيات مكتبات) بقائمة جوار، احسب درجة كل عقدة، ابحث عن العقد المعزولة (القسم 5).
7. اكتب جدولة مهام بطابور أولوية (القسمان 4، 6).

**المخرج:** مكتبة صغيرة لهياكل البيانات بالاختبارات، مع جدول قياسات يقارن تنفيذاتك بالهياكل المدمجة في بايثون.

**معيار الانتقال:**

- تذكر كلفة العمليات الأساسية لكل هيكل دون مراجعة.
- تختار هيكلًا لمسألة جديدة، تبرر الاختيار بالمفاضلات.
- تشرح لماذا يعمل البحث في القاموس بزمن شبه ثابت، متى ينهار هذا.
- تربط بين أشجار B، الفهارس التي رأيتها في المرحلة الثالثة.
