# المرحلة الخامسة [P05]: الخوارزميات (Algorithms)

أنا مهندس برمجيات أهدف إلى بناء فهم هندسي متين يساعدني على تحليل المشكلات، وفهم سلوك الأنظمة، واتخاذ قرارات تقنية مبررة، وتطوير برمجيات موثوقة قابلة للاختبار والصيانة والتوسع. أفضّل استخدام **Python** و**PostgreSQL**، وأعتمد **FastAPI** في المسار التطبيقي لتطوير الخدمات الخلفية؛ لذلك تربط هذه الخطة بين الأسس النظرية والتطبيق العملي باستخدام هذه التقنيات.

**هدف المرحلة:** اختيار الخوارزمية وفق المسألة، تفسير صحتها، كفاءتها، المفاضلة بين البدائل.

## 1. تحليل الخوارزميات (Algorithm Analysis)

- تحليل الحلقات المتداخلة - Analyzing Nested Loops
- تحليل الخوارزميات العودية، النظرية الرئيسية - Analyzing Recursive Algorithms, Master Theorem
- التحليل المستهلك - Amortized Analysis
- المفاضلة بين الزمن، الذاكرة - Time-Space Trade-offs
- إثبات صحة الخوارزميات، ثوابت الحلقة - Algorithm Correctness, Loop Invariants

## 2. البحث، الترتيب (Searching, Sorting)

- البحث الخطي، البحث الثنائي - Linear Search, Binary Search
- البحث الثنائي على الإجابة - Binary Search on the Answer
- الترتيب البسيط: الفقاعات، الإدراج، الاختيار - Simple Sorts: Bubble, Insertion, Selection
- الترتيب الفعال: الدمج، السريع، الكومة - Efficient Sorts: Merge, Quick, Heap
- الترتيب بالعد - Counting Sort
- الاستقرار، الترتيب الموضعي - Stability, In-Place Sorting
- الترتيب في بايثون - Sorting in Python (Timsort, Key Functions)

## 3. العودية، أساليب التصميم (Recursion, Design Strategies)

- العودية، مكدس الاستدعاءات، حالة القاعدة - Recursion, Call Stack, Base Case
- القوة الغاشمة - Brute Force
- التقسيم، الحل - Divide and Conquer
- الخوارزميات الجشعة - Greedy Algorithms
- البرمجة الديناميكية: الحفظ، الجدولة - Dynamic Programming: Memoization, Tabulation
- البحث بالتراجع - Backtracking

## 4. أنماط حل المسائل (Problem-Solving Patterns)

- المؤشران - Two Pointers
- النافذة المنزلقة - Sliding Window
- المجاميع التراكمية - Prefix Sums
- العد بجداول التجزئة - Hash-Based Counting
- معالجة الفترات - Intervals

## 5. خوارزميات الرسوم البيانية (Graph Algorithms)

- البحث بالعرض أولًا، البحث بالعمق أولًا - Breadth-First Search, Depth-First Search
- الكشف عن الدورات، المركبات المتصلة - Cycle Detection, Connected Components
- الترتيب الطوبولوجي - Topological Sorting
- أقصر المسارات: ديكسترا، بيلمان-فورد - Shortest Paths: Dijkstra, Bellman-Ford
- الأشجار الممتدة الصغرى: كروسكال، بريم - Minimum Spanning Trees: Kruskal, Prim

## 6. خوارزميات النصوص، التجزئة (String Algorithms, Hashing)

- مطابقة النمط - Pattern Matching
- التجزئة المتدحرجة - Rolling Hash
- مسافة التحرير، أطول تتابع مشترك - Edit Distance, Longest Common Subsequence
- التجزئة التشفيرية مقابل التجزئة العادية - Cryptographic vs Non-Cryptographic Hashing

## 7. المنهج العملي لحل المسائل (Problem-Solving Method)

- تحليل نص المسألة، القيود - Problem Statement, Constraints Analysis
- تصميم الحل، مقارنة الحلول - Solution Design, Solution Comparison
- بناء حالات الاختبار، الحالات الحدية - Test Case Design, Edge Cases
- تفسير التعقيد، تبريره - Complexity Reasoning

## التدريبات العملية (Practical Exercises)

1. نفذ خمس خوارزميات ترتيب، قس زمنها على مدخلات مرتبة، معكوسة، عشوائية بأحجام مختلفة، قارن النتائج بتوقعك (القسمان 1، 2).
2. حل 40 مسألة موزعة: 10 للمصفوفات، النصوص بالأنماط، 8 للبحث الثنائي، 8 للعودية، التراجع، 8 للبرمجة الديناميكية، 6 للرسوم البيانية؛ لكل مسألة اكتب الفكرة، التعقيد، حالة حدية (الأقسام 2 إلى 5).
3. حل مسألة تغيير العملات بثلاث طرق: القوة الغاشمة، الجشع، البرمجة الديناميكية؛ بيّن متى يفشل الجشع (القسم 3).
4. أوجد أقصر طريق في خريطة صغيرة، رتب بناء مكتبات ذات تبعيات، اكتشف تبعية دائرية (القسم 5).
5. ابنِ أداة مقارنة ملفات بسيطة تعتمد على أطول تتابع مشترك (القسم 6).
6. قارن حلين لمسألة واقعية، مثل إزالة التكرار من 10 ملايين سجل: قس الزمن، الذاكرة، اختر الأنسب بحجة مكتوبة (القسمان 1، 7).
7. لكل خوارزمية كتبتها: برهان قصير لصحتها بثابت حلقة أو باستقراء (القسم 1).

**المخرج:** مستودع مسائل محلولة، لكل حل ملف يحتوي الفكرة، التعقيد، الاختبارات؛ تقرير مقارنة بين ثلاثة حلول لمسألة واحدة.

**معيار الانتقال:**

- تحل مسألة متوسطة جديدة، تفسر تعقيدها.
- تعرف متى يُستخدم كل نمط: المؤشران، النافذة، البرمجة الديناميكية، التراجع.
- تبرهن صحة خوارزمية بسيطة.
- تربط كل خوارزمية بالهيكل المناسب لها.
